# Stroke-Data-Analytics-Phase-2


An **interactive Streamlit dashboard** to analyze stroke-related healthcare data. This app allows users to explore patient data through various lifestyle and medical filters to uncover meaningful health insights.

---

## 📊 Features

- Upload stroke dataset in CSV format
- Interactive filters for:
  - Age range
  - Average glucose level
  - Hypertension
  - Smoking status
  - Dietary habits
  - Alcohol consumption
  - Chronic stress
  - Sleep hours
  - Family history of stroke
  - Education level
  - Income level
  - Region
- Styled and user-friendly data table
- Download filtered results as a CSV file
- Custom dashboard theme using HTML/CSS

---

## 🛠️ Tech Stack

- **Python 3**
- **Streamlit** – For UI and interaction
- **csv** module – For reading and writing data
- **HTML/CSS** – For styling the dashboard

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/stroke-data-analytics-dashboard.git
cd stroke-data-analytics-dashboard
```

### 2. Install Dependencies

```bash
pip install streamlit
```
### 3. Run the App

```bash
streamlit run app.py
```

### 📂 Required Dataset Columns

Ensure your CSV file includes the following columns:

- Age
- Average Glucose Level
- Hypertension
- Smoking Status
- Dietary Habits
- Alcohol Consumption
- Chronic Stress
- Sleep Hours
- Family History of Stroke
- Education Level
- Income Level
- Region
